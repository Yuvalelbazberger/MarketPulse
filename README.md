# MarketPulse — Daily Market Snapshot

MarketPulse is a lightweight market analysis project that produces a daily snapshot of key assets based on performance, trend context, and volatility.

The project ingests historical market data, computes essential indicators (daily return, moving averages, volatility), and generates a clean, dashboard-ready dataset.

The final output is an interactive Tableau dashboard that highlights top movers, risk vs. return dynamics, and trend positioning in a clear and intuitive way.

**Tech stack:** Python (pandas), DuckDB/CSV, Tableau  
**Output:** Daily market snapshot + interactive dashboard
